# 🎯 Linked Brushing App

This Streamlit app demonstrates **Altair linked brushing**  
with the `cars()` dataset from `vega_datasets`.

## Run locally

```bash
# Clone the repo
git clone https://github.com/YOUR_GITHUB_USERNAME/linked_brush_app.git
cd linked_brush_app

# Install dependencies
pip install -r requirements.txt

# Run app
streamlit run app.py
